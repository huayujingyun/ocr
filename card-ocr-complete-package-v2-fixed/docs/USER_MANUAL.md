## 快速开始

### 第一次使用

1. **访问应用**
   - 浏览器打开：http://localhost:5000
   - 或双击运行 `start.bat` 后自动打开

2. **设置识别模板**（推荐）
   - 点击"设置识别模板"按钮
   - 上传一张清晰的卡片图片
   - 框选卡号和密码区域
   - 保存模板

3. **开始识别**
   - 点击"上传图片"
   - 选择多张卡片图片
   - 点击"开始识别"
   - 等待识别完成

4. **导出结果**
   - 检查识别结果
   - 编辑错误项
   - 点击"导出Excel"

## 设置识别模板

### 为什么要设置模板？

使用模板可以：
- ✅ 大幅提高识别准确率（从90%提升到98%+）
- ✅ 加快识别速度（提升2-3倍）
- ✅ 减少误识别

### 设置步骤

1. **进入模板设置页面**
   - 点击主页面的"设置识别模板"按钮
   - 或直接访问：http://localhost:5000/template

2. **上传参考图片**
   - 点击"上传参考图片"
   - 选择一张清晰、标准的卡片图片
   - 图片要求：
     * 分辨率：800x600以上
     * 格式：JPG、PNG
     * 内容：卡号和密码清晰可见

3. **框选识别区域**

#### 框选卡号区域
1. 在图片上点击"框选卡号区域"
2. 使用鼠标在卡号位置绘制矩形框
3. 确保框内只包含卡号数字
4. 调整边框，精确覆盖卡号区域

#### 框选密码区域
1. 在图片上点击"框选密码区域"
2. 使用鼠标在密码位置绘制矩形框
3. 确保框内只包含密码
4. 调整边框，精确覆盖密码区域

4. **预览和调整**
   - 系统会显示裁剪后的区域预览
   - 检查是否准确
   - 如有偏差，重新框选

5. **保存模板**
   - 点击"保存模板"按钮
   - 模板会保存到浏览器本地存储
   - 下次使用时会自动加载

### 模板示例

```
参考图片：
┌─────────────────────────────────────┐
│                                     │
│  购物卡                          │
│                                     │
│  卡号：1234 5678 9012 3456           │
│         [卡号框选区域]               │
│                                     │
│  密码：ABCD1234                      │
│       [密码框选区域]                 │
│                                     │
│  有效期：2025/12/31                  │
│                                     │
└─────────────────────────────────────┘
```

### 多模板支持

如果需要识别多种类型的卡片：
1. 为每种卡片类型创建一个模板
2. 给模板命名（如"沃尔玛卡"、"加油卡"）
3. 识别时选择对应的模板

## 批量识别

### 上传图片

#### 方式1：点击上传
1. 点击"上传图片"按钮
2. 在文件选择对话框中：
   - 按住Ctrl键：多选图片
   - 按住Shift键：连续选择
   - 或直接按Ctrl+A选择所有图片

#### 方式2：拖拽上传
1. 将图片文件拖拽到上传区域
2. 支持一次性拖拽多张图片

#### 方式3：文件夹上传
1. 点击"上传图片"
2. 选择文件夹
3. 系统会自动识别文件夹中的所有图片

#### 图片要求

| 参数 | 要求 |
|------|------|
| 格式 | JPG、JPEG、PNG、BMP |
| 大小 | 最大10MB/张 |
| 分辨率 | 推荐800x600以上 |
| 数量 | 最多100张/批 |

### 开始识别

1. **选择识别模式**
   - 使用模板（推荐）：已设置模板时自动选择
   - 传统OCR：没有模板时使用

2. **点击"开始识别"**
   - 系统会逐张识别图片
   - 显示识别进度

3. **等待识别完成**
   - 单张识别：约0.5-2秒
   - 批量识别：根据数量而定
   - 10张图片：约5-10秒

### 识别过程

```
识别进度：
┌─────────────────────────────────────┐
│  正在识别... 3/10                    │
│  ████████░░░░░░ 40%                 │
│                                     │
│  当前图片：card_003.jpg             │
│  预计剩余时间：5秒                   │
└─────────────────────────────────────┘
```

### 识别结果

识别完成后，结果会显示在列表中：

| 序号 | 文件名 | 卡号 | 密码 | 状态 | 操作 |
|------|--------|------|------|------|------|
| 1 | card_001.jpg | 1234... | ABC... | ✓ 成功 | [编辑] [删除] |
| 2 | card_002.jpg | 5678... | XYZ... | ✓ 成功 | [编辑] [删除] |
| 3 | card_003.jpg | - | - | ✗ 失败 | [重新识别] [删除] |

## 编辑识别结果

### 编辑单个结果

1. 点击结果行的"编辑"按钮
2. 在弹出的对话框中：
   - 查看原始图片
   - 查看裁剪区域
   - 编辑卡号和密码
   - 点击"保存"

### 批量编辑

1. 勾选多个需要编辑的结果
2. 点击"批量编辑"按钮
3. 在弹出的对话框中编辑
4. 点击"保存"

### 重新识别

如果某张图片识别失败：

1. 点击该行的"重新识别"按钮
2. 或更换识别模式：
   - 从"模板识别"切换到"传统OCR"
   - 或从"传统OCR"切换到"模板识别"

### 删除结果

1. 点击"删除"按钮
2. 确认删除

导出文本格式的识别结果：

**格式**：

1,1234567890123456,ABCD1234

## 高级功能

### 条码识别

系统支持识别卡片上的条码：

1. 上传卡片图片
2. 系统会自动识别条码（如有）
3. 识别结果显示在列表中

系统自动对图片进行预处理：
- 灰度化
- 对比度增强

可以手动选择预处理方式：
- 原始图片

## 常见问题

### Q1：识别准确率不高？

**可能原因**：
- 图片质量差
- 模板设置不准确
- 卡片格式变化

**解决方案**：
1. 提高图片质量（清晰度、光线）
2. 重新设置识别模板
3. 尝试不同的预处理方式

### Q2：识别速度慢？

**可能原因**：
- 批量识别数量多
- 系统资源不足

**解决方案**：
1. 减少批量数量（建议20张以内）
2. 关闭其他占用资源的程序
3. 使用GPU加速（如果可用）

### Q3：无法识别某些卡片？

**可能原因**：
- 卡片格式不支持
- 图片过于模糊

**解决方案**：
1. 手动输入
2. 使用传统OCR模式
3. 提高图片质量

### Q4：导出Excel失败？

**可能原因**：
- 数据量过大
- 浏览器限制

**解决方案**：
1. 分批导出（每次不超过100张）
2. 使用Chrome浏览器
3. 清除浏览器缓存
