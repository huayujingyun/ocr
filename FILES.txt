==================================
部署步骤
==================================

1. 环境检查
   chmod +x check-deploy.sh
   ./check-deploy.sh

2. 安装依赖
   pnpm install

3. 构建项目
   pnpm build

4. 启动服务
   pnpm start

或使用快速启动：
   chmod +x start.sh
   ./start.sh

==================================
主要功能流程
==================================

1. 设置模板（首次）
   → 访问 /template
   → 上传标准图片
   → 框选区域
   → 保存

2. 上传图片
   → 批量上传卡片图片
   → 自动裁剪

3. 识别
   → 点击"开始识别"
   → 逐张识别
   → 实时显示

4. 编辑
   → 查看结果
   → 修正错误

5. 导出
   → 导出Excel
   → 下载文件
