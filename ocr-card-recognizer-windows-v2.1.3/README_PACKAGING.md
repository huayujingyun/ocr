## Quick Installation

### Prerequisites

1. **Python 3.12**: Download from https://www.python.org/downloads/
   - During installation, check "Add Python to PATH"
   - Verify installation: `py --version`

2. **Node.js 18+**: Download from https://nodejs.org/
   - Install pnpm: `npm install -g pnpm`

3. **Git** (optional): For version control

### Installation Steps

1. **Extract the package**
   ```
   Right-click the .tar.gz file and "Extract Here"
   ```

2. **Install backend dependencies**
   ```
   cd backend
   py -m pip install -r requirements.txt
   ```

3. **Install frontend dependencies**
   ```
   cd ..
   pnpm install
   ```

4. **Build the frontend**
   ```
   pnpm run build
   ```

### Running the Application

**Terminal 1 - Start Backend:**
```
cd backend
py -m uvicorn main:app --host 0.0.0.0 --port 8000
```

**Terminal 2 - Start Frontend:**
```
cd ..
pnpm run start
```

**Open Browser:**
```
http://localhost:5000
```

## Troubleshooting

### Python Command Not Found
If `python` command doesn't work, use `py` command instead:
```
py --version
```

### Port Already in Use
If port 5000 or 8000 is already in use, change the port number:
```
# Backend: Change --port 8000 to --port 8001
# Frontend: Change -p 5000 to -p 5001
```

### CSS Not Loading
If styles don't appear:
1. Clear browser cache (Ctrl+Shift+Delete)
2. Force refresh (Ctrl+Shift+R)
3. Check if .next directory exists and run `pnpm run build`
