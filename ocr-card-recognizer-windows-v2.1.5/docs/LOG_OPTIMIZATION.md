# 前端日志优化说明 v2.1.5

## 🎯 优化目标

减少前端控制台日志输出，降低系统卡顿，只显示关键统计信息。

---

## 📊 日志级别系统

### 新增日志级别控制

新增了日志级别系统，支持以下级别：

| 级别 | 描述 | 输出内容 |
|------|------|---------|
| `none` | 完全静默 | 不输出任何日志 |
| `error` | 仅错误 | 只输出错误信息 |
| `warn` | 警告和错误（默认） | 输出警告和错误 |
| `info` | 信息、警告和错误 | 输出所有信息 |
| `debug` | 调试、信息、警告和错误 | 输出所有日志 |

### 默认设置

**默认日志级别**: `warn`

这意味着：
- ✅ 显示错误信息
- ✅ 显示警告信息
- ❌ 不显示详细的信息日志
- ❌ 不显示调试日志

## ⚙️ 如何调整日志级别

### 方法1：通过浏览器控制台

打开浏览器控制台（F12），输入：

```javascript
// 设置为只显示错误
localStorage.setItem('log-level', 'error');

// 设置为完全静默
localStorage.setItem('log-level', 'none');

// 设置为显示所有日志
localStorage.setItem('log-level', 'debug');

// 刷新页面生效
location.reload();
```

### 方法2：通过代码

在应用启动时设置：

```typescript
import { logger } from '@/lib/utils';

// 设置日志级别
logger.setLevel('error'); // 只显示错误
logger.setLevel('debug'); // 显示所有日志
```

## 🚀 使用建议

### 日常使用

**推荐设置**: `warn`（默认）

```javascript
localStorage.setItem('log-level', 'warn');
```

显示：
- ✅ 错误信息
- ✅ 警告信息
- ✅ 统计信息

### 调试问题

**推荐设置**: `debug`

```javascript
localStorage.setItem('log-level', 'debug');
```

显示所有日志，方便排查问题。

### 完全静默

**推荐设置**: `none`

```javascript
localStorage.setItem('log-level', 'none');
```

完全不输出日志，只显示用户界面信息。

## 📝 技术细节

### 实现原理

1. **日志级别系统**
   - 使用 `localStorage` 存储日志级别
   - 默认级别为 `warn`
   - 支持动态切换

2. **日志分类**
   - `logger.info()`: 普通信息（debug 级别显示）
   - `logger.error()`: 错误信息（所有级别显示）
   - `logger.warn()`: 警告信息（warn 及以上级别显示）
   - `logger.debug()`: 调试信息（debug 级别显示）
   - `logger.stats()`: 统计信息（warn 及以上级别显示）

3. **性能优化**
   - 减少 console.log 调用次数
   - 减少字符串拼接操作
   - 减少控制台渲染负担

## 🆕 新增功能

### logger.setLevel()

设置日志级别：

```typescript
import { logger } from '@/lib/utils';
logger.setLevel('debug');
```

### logger.getLevel()

获取当前日志级别：

```typescript
import { logger } from '@/lib/utils';
const level = logger.getLevel(); // 'warn', 'debug', etc.
```

### logger.stats()

输出统计信息（关键信息）：

```typescript
logger.stats('识别完成', { success: 10, total: 10 });
```

## ⚠️ 注意事项

1. **日志级别持久化**
   - 日志级别保存在 `localStorage`
   - 清除浏览器缓存会重置为默认值

2. **生产环境**
   - 默认只显示警告和错误
   - 不显示详细的信息日志
   - 不显示调试日志

3. **开发环境**
   - 可以设置为 `debug` 查看所有日志
   - 建议开发完成后改回 `warn`
